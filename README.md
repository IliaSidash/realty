# Квартиры под сдачу

Личная страница для просмотра квартир на Кипре, где аренда покрывает ипотеку. Данные собирает [bazaraki-parser](https://github.com/IliaSidash/bazaraki-parser) (приватный) в Supabase.

- Вход по ссылке на почту (Supabase Auth). Читать данные могут только адреса из таблицы `app_users`.
- В браузере только publishable-ключ: без входа разрешённым адресом он ничего не открывает.
- Аренда, расстояние до моря и возраст дома посчитаны парсером. Платёж и остаток считаются на странице, параметры ипотеки сохраняются в браузере.
- Статический сайт без сборки: GitHub Pages раздаёт файлы как есть.
